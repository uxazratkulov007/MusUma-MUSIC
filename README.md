# MusUma

MusUma — tinglash uchun oddiy musiqa sayti.

## Ishga tushirish

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Brauzerda oching: http://127.0.0.1:8000

## Imkoniyatlar

- Hero landing va **MusUma** brendi
- Trek ro‘yxati, janr filtri, qidiruv
- Kayfiyat bo‘yicha kashf etish
- Pastki player: play/pause, next/prev, seek

Demo audio: [SoundHelix](https://www.soundhelix.com/) namunalari (qisqartirilgan).
